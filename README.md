## Disk layout:
Sector 1 - Stage 1 Bootloader
Sector 2 - Stage 2 Bootloader

Sector 2048 Onwards - FAT32 Disk

## Building
Use the `build.py` python script to build the OS. Use the appropriate arguments, makefiles are overrated.
